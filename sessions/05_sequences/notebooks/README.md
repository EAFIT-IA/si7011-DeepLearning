# Session 05 notebooks

**How does a network remember the past?** Each notebook changes **one thing** at a time and compares the result with the previous one: before running a cell, guess what will happen; after running it, check whether you were right. Everything is already written and runs as is; each notebook ends with a short *Tu turno* section.

Notebooks 1, 2 and 3 use **Jena Climate**: 14 weather variables every 10 minutes, 2009–2016, from the Max Planck Institute for Biogeochemistry. The task is the same in all three: 5 days of hourly readings → temperature 24 hours later. Notebook 4 uses **IMDB** (25 000 movie reviews to train, 25 000 to test, positive or negative); it reads the Hugging Face files `stanfordnlp/imdb` from a `data/` folder next to the notebook or downloads them (keep *Internet* on in Kaggle), and it wants a GPU. Its section 9 also downloads the pretrained GloVe vectors (130 MB) from GitHub the first time it runs. Notebook 5 generates its own data (Spanish sentences that contain a date). Notebook 6, the integrating exercise, uses the hourly **Bike Sharing** dataset from UCI (Capital Bikeshare, Washington D. C., 2011–2012): it reads `hour.csv` from `data/` (or from an input you added on Kaggle) and otherwise downloads the UCI zip, so keep *Internet* on. It has four TODOs to complete and logs your runs to MLflow. Notebooks 1, 2, 3, 5 and 6 run on a laptop CPU in a few minutes.

**Before class, on Kaggle:** add the dataset [`mnassrib/jena-climate`](https://www.kaggle.com/datasets/mnassrib/jena-climate) with **Add Input** (notebooks 1, 2 and 3). The notebooks check the data before using it: they drop repeated timestamps, set the wind sensor error code (−9999) to 0 and skip windows that would jump a gap in the series. On Colab, the notebooks download it with your `KAGGLE_API_TOKEN` secret, the same one from Session 01; on your computer or on Lightning, put `jena_climate_2009_2016.csv` in a `data/` folder next to the notebook. Each notebook prints the source it used: check it.

| # | Notebook | The question it answers |
|---|---|---|
| 1 | [Series y ventanas](sesion_05_1_series_ventanas.ipynb) | ¿Qué es un ejemplo en una serie de tiempo, y qué número hay que superar? |
| 2 | [RNN y retropropagación en el tiempo](sesion_05_2_rnn_bptt.ipynb) | ¿Hasta dónde llega el gradiente en una red recurrente? |
| 3 | [LSTM y GRU](sesion_05_3_lstm_gru.ipynb) | ¿Qué cambia con un camino aditivo para la memoria, y cuándo sirve? |
| 4 | [Texto y embeddings](sesion_05_4_texto_embeddings.ipynb) | Para el sentimiento de una reseña, ¿importa el orden de las palabras? |
| 5 | [Seq2seq y atención](sesion_05_5_seq2seq_atencion.ipynb) | ¿Qué cabe en un solo vector, y qué cambia cuando el decodificador puede mirar atrás? |
| 6 | [Ejercicio integrador: Bike Sharing](sesion_05_6_integrador_bike_sharing.ipynb) | ¿Cuántas horas adelante le gana tu red a la respuesta obvia? Cuatro TODOs, con MLflow |
