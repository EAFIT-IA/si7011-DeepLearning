# SI7011 — Deep Learning

Material del curso **SI7011 — Deep Learning**, Universidad EAFIT.

## Estructura del curso

El curso se organiza en seis sesiones de cuatro horas:

1. **Learning** — How does a neural network learn?
2. **Deep Training** — Why can we train deep neural networks?
3. **Architectures for Vision** — From convolution to Vision Transformers
4. **Representation Learning** — Learning useful representations without explicit labels
5. **Sequences & Foundation Models** — From recurrent memory to pretrained models
6. **Adaptation, Evaluation & Deployment** — From pretrained models to reliable applications
